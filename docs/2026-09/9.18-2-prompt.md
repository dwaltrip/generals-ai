## Session guidelines

All decisions in the docs are provisional and should be confirmed in chat before the corresponding code is written. 9.18-1 marks which parts of the regen report are firm and which are first picks.

Working style, carried over from earlier sessions:

- Discussion before code, one piece at a time. Judgment calls are surfaced rather than resolved silently.
- Skeletons before implementations: typed signatures and `TODO(sketch)` comments in the real file locations, no verbose docstrings.
- Question an interface before designing around it. Much of the codebase is agent-authored, and an awkward fit is a hint that existing code should change.
- Prose register: plain writing, in code comments as much as in docs.
