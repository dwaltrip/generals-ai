# Per-epoch in-training stratified dumps — investigate + design proposal

## Session Goal

Make every training run optionally write a per-frame stratified dump for each epoch's val pass, so erosion/optimum questions (which epoch is the value head's true optimum, what the late-game signal does over training) are answerable without manual per-checkpoint dumps.

Investigate thoroughly, then write a concise design proposal for my review. Do not implement yet.

## Starting context 

**leanings from prior discussion — verify against the code, push back where the code disagrees.**

1. One record schema, two producers, one consumer. The offline harness (packages/training/scripts/stratified_val_loss_analysis.py, `dump` subcommand) defines the per-frame record (value distribution + CE, policy CE/entropy/top-k, pass prob, players_alive, frame_t, p_start, sample_idx). Extract record-building into training/bc/eval/dump.py; in-training val pass and offline script both produce the identical format; the existing `report` subcommand consumes either unchanged.
2. Inert by default: a TrainConfig flag (e.g. dump_val_frames), default off, flag-off runs byte-identical in behavior (same convention as the 6.10-3 levers).
3. The non-free parts to investigate: (a) threading include_frame_info=True into the val dataset when the flag is on — verify collation handles the extra scalars and flag-off paths are untouched; (b) run_val (training/bc/eval/run.py) currently reduces via meters — the dump path needs per-frame capture before reduction (stash to CPU per batch, write at epoch end). Check memory/throughput implications and where files should land in the run dir (probably <run>/analysis/, matching the offline tool's conventions).
4. Caveats to handle/document, not over-engineer: cloud val runs under autocast (records will be fp16-derived where offline dumps were fp32 — cast on write, note the comparability caveat); artifact size ~1–6 MB/epoch must come back in the Modal artifact pull (check eval-tools/training pull scripts for what gets synced).
