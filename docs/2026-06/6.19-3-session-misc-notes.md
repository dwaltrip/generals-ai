**1. The value head is the north star — everything else is a gate.** The biggest one. The elim-head's actual purpose, its original reason for existing, is to *improve the value head*. You said no — minimal overfit / a val curve that keeps falling (vs. the current ep3 peak-then-degrade) is itself wanted. You'd even settle for a *plateau* if it also beats the heuristics.

**4. The two distinct flavors of overfit work.** A clean distinction you drew that the prompt had been blurring:
- **(1) General reductions** — low/no downside, kept permanently on merit (dropout, weight decay, soft targets, a standing lit survey).
- **(2) Temporarily tamping high-fingerprint channels** — pull parts of the "easy path" so the model has nowhere to go but the harder, generalizing road. *Possibly temporary*: restore later, and not necessarily as-was — maybe in a **less-fingerprinty form** (summarized / lower-resolution). n=5 dense-history is the canonical case; it generalizes to *any* dense/semi-dense channel with a strong fingerprint.

**5. The theory under (2), and its honest caveat.** If the true generalization signal is hard-to-parse-but-not-inaccessible, the model grabs easy memorization handles first; suppress them and it's pushed onto the true signal *and/or* the lever comparison gets legible. You flagged this as just-formed — the general principle is grounded (shortcut-learning / feature-dropout literature), but the specific remove-then-restore protocol is bespoke, not confirmed standard practice.

## Joint synthesis

**6. The layered success metric (Tier 0 / Tier 1).** Tier 0 = head is *sound* (beats best model-free heuristic + wins its disagreements; healthy curve that at least plateaus). Tier 1 = head *improves the value head*. This replaced the incomplete "val crosses 47.2%" line and is now canonical in 6.19-2 §Direction.

**7. The causal-ordering / anti-regularizer insight** — the load-bearing connection. A *memorizing* aux head is an anti-regularizer: it injects idiosyncratic gradients into the shared trunk, so it can only no-op or hurt value. A *generalizing* aux head both enriches and regularizes. So a healthy Tier-0 curve is the **precondition** for helping value, not just a milestone before it. This is what makes the overfit goal and the value-head goal *the same pursuit* rather than two objectives — and it's the cleanest argument for why "get the head sound" gates "use it to help value." (Held as a hypothesis.)

**8. Two channels by which an aux head helps the primary.** "Help value" decomposes into **representation enrichment** (the trunk encodes death/threat structure value draws on) and **trunk regularization** (the aux gradient makes the shared trunk more robust). Your trunk-robustness interest is that second channel — the *mechanism* under "help value," not a separate goal.

Soft targets are what fixed the value head's n→20 overfit; the elim-head is the *one head still on hard CE* and the one now overfitting. So the imminence-weighted soft target (parked in 6.18-9 as a "tick-latency fix") is plausibly the known overfit remedy applied to the matching symptom — double duty — and it's a flavor-(1) lever because it removes no signal.
