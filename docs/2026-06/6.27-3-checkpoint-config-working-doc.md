## 2. As-built structure (supersedes 6.27-1 §4)

Homes by concern (config *shape* / model *construction* / `.pt` *format & I/O*):

| Home | Holds |
|---|---|
| `bc/config` *(created in step 2)* | config shape: `CONFIG_VERSION`, `MIGRATIONS` + migrate dispatch, `resolve_checkpoint_config`, the config↔jsonable (Path) helpers. Torch-free. |
| `bc/model_builder.py` | `build_model`, `ConfiguredModel`. |
| `bc/storage/checkpoint.py` | the `.pt` adapter: `load_checkpoint`, the v1 serializer *(step 2)*, `validate_in_ch` *(step 2)*, `is_versioned_checkpoint`. |
| old `bc/checkpoint.py` | the current legacy reconstruction (`arch_for_load`, `LEGACY_ARCH`/`LEGACY_OBS_CFG`), the discriminators (`is_combined_checkpoint`, `is_arch_bearing`, `is_legacy_checkpoint`), `ckpt_name`. Shrinks as logic migrates into `storage`/`config`. |

Settled structural decisions (the deltas from 6.27-1 §4):

- **`ConfiguredModel` lives in `model_builder`** — it's the assembled model + config, a model-domain object (chunk-2 makes it the home for `cfg` and the variant-meta). `cfg` is a property delegating to `model.cfg`. `config` is `None` for legacy checkpoints — a v0 `.pt` records only the arch (reachable via `cfg`), not the full `TrainConfig` (the recipe lived in the run-dir sidecar). Whether the `None` ever goes away is the uniform-vs-graded fork (6.27-1 appendix B), still open.
- **`is_versioned_checkpoint` is a discriminator** — presence of the config block — **not validation**. Validation (migrate + construct + run validators) lives inside `resolve_checkpoint_config`.
- **The strangler arrangement:** the new `storage/checkpoint.py` is written clean and delegates *back* to old `checkpoint.py` (it imports `arch_for_load`, `is_combined_checkpoint`). Old `checkpoint.py` is **not moved** — it's cleaned up later. The dependency edge (new → old) inverts as the reconstruction migrates into `storage`.
- **`build_model` is the single construction seam**, shared by `load_checkpoint` and `TrainingState.fresh`.

## 3. Conventions

- **`# NOTE(refactor-note):` / `# TODO(refactor-note):`** mark transient or placeholder reasoning tied to the refactor — greppable, so a later sweep can confirm each is resolved before the refactor closes.
- **`$NAME` placeholder refs** (e.g. `$LEGACY_EXPLAINER`) stand in for an explanation to be written once and pointed at from several sites, rather than repeated inline. One is currently outstanding (§6).
- **Docstrings** state the evergreen "what" tightly; transient or forward-looking "why" goes into a refactor-note, not the docstring. The new `storage` / `model_builder` code is the style baseline — the old `checkpoint.py` prose is not (it predates the comment cleanup and is uneven).
- **No step/chunk lingo** ("step 2", "chunk-1") in code prose — it decays. Describe the architecture as-is, or use a refactor-note for genuinely transient state.

## 4. Traps & constraints

- **`in_ch` is a derived `@property`** on `ModelConfig`, not a field, so `asdict(TrainConfig)` omits it. The v1 serializer writes it as a top-level key explicitly; the config block stays a pure `asdict`.
- **Typing a just-loaded checkpoint:** the function that *consumes* the contents takes `Any` (what `torch.load` returns); the discriminators that only *inspect* structure take `object` (+ `TypeGuard`). Mixing them widens to `Any | object` and trips pyright on `load_state_dict`.
- **ruff B018:** a trailing attribute access as a bare statement (e.g. `load_checkpoint(...).model`, notably inside `pytest.raises`) is flagged useless — drop the `.model` (the call raises before it anyway).
- **`_archive` is exempt:** `pyrightconfig.json` excludes `**/_archive/**`, and ruff doesn't resolve import targets, so an archived file importing a since-deleted symbol is fine (matches the existing `_archive/` convention).
- **`weights_only=True`** on every checkpoint load forces the config block's `Path` fields to be stringified on write and re-wrapped on read — see 6.27-1 §2.

## 5. Validation approach

- Run the `training`, `self-play`, and `eval-tools` suites (per affected package).
- Callers without fast-test coverage — smoke manually when touched: `stratified_val_loss_analysis`, `self-play/cli.py`, `eval_poc.py`, `probe_row_independence`.
- Lock load-path invariants with explicit tests — e.g. `is_arch_bearing`'s v0 answer (and thus the inference `model_key`) must stay byte-identical across the §5.1 fix.
