## The four items

Suggested order — each is independently shippable, so it's fine to stop early.

1. **A — `ownership_transition` signed encoding.** `training/bc/obs.py:641`. Currently a binary cell-changed mask. Design is a signed scalar from a lookup over (older_owner, newer_owner) pairs. Spec: [`5.05-1`](./5.05-1-observation-tensor-design-part2.md) §G.
2. **A' — `army_delta` production subtraction.** `obs.py:643-644`. Currently `sign · log1p(|Δ|)` of raw delta. Design subtracts per-cell expected production (general/city = +1/tick, owned = +1 every 25 ticks at the boundary) before computing the delta. Spec: 5.05-1 §G + §7.2.
3. **C — `opp_N_has_seen` channels.** 7 new channels, currently absent. Per-opp binary mask: 1 at any cell ever observed within opponent N's Moore-neighborhood vision. Per-tick state update in `step_memory`; new entries in `CHANNEL_ORDER`; first-conv `in_channels` goes 89 → 96 in `training/bc/model.py`. Spec: 5.05-1 §3.4.2 + §I.
4. **B (optional) — `opp_N_city_inference`.** `obs.py:565-567`. 7 channels currently zero-stubbed. Heuristic: estimate per-opp city count from army growth during "peacetime" windows. Design is sketch-only (5.05-1 §F: "Inferred city count from peacetime growth. -1 when unclear") — you'd be inventing the window size + peacetime threshold yourself. **Cap at ~2 hours; defer if the heuristic doesn't feel stable** — a biased signal here is plausibly worse than all-zeros (the model has to learn to discount it).
