## Key decisions made last session

- BFS is cheap at map scale (~900 cells), use freely — no need for approximations
- Explore targets fog tiles (not restricted to "never-seen" — includes re-fogged territory, which biases toward reclaiming lost ground)
- Kill-shot has no max_moves constraint (margin handles distance penalty economically)
- Defend always responds with best-effort (no min_army gate — doing nothing is never correct)
- Side-gather dist-2 out of scope for v1 (single-move side-gathers only)
- Owned tiles can't be adjacent to fog (Moore visibility) — this informed several spec corrections
