Pure structural extraction from `train.py`. Zero behavior change for training runs, save for one intentional artifact rename (`console.log` → `run.log`).

## End-state module map (PR 1 slice only)

```
training/bc/
  train.py        — bc_run, run_loop, train_one_epoch, _measure_model_flops_per_sample,
                    print_epoch_summary (new), build_dataloader (new), _fmt_metric, _ckpt_name, _save_checkpoint
  run_logger.py   — RunLogger (new file)
  run_dir.py      — initialize_run_dir (moved from train.py), RunArtifacts (new file)
```

`run_loop` keeps its name this PR — it only becomes `train_loop(state, ...)` in PR 3 when `TrainingState` exists. `checkpoint.py` / `state.py` / `resume_warmup.py` are later PRs.

## New abstractions

### `RunLogger` (`run_logger.py`)
- Single source of truth for the JSONL format. Owns `batches.jsonl` + `epochs.jsonl`.
- `__init__(run_dir, suffix="")` → computes paths `batches{suffix}.jsonl` / `epochs{suffix}.jsonl`, files unopened. `suffix` is `""` this PR; the param exists now so PR 4 doesn't reshape the constructor.
- `open()` opens both line-buffered (`buffering=1`); `close()` closes them.
- `log_batch(record)` / `log_epoch(record)` — absorb the current `_write_jsonl` (`json.dumps(record) + "\n"`). The line-buffered `tail -f` comment moves here.

### `RunArtifacts` (`run_dir.py`)
- Per-run runtime struct + context manager. PR 1 fields: `run_dir, ckpt_dir, logger, flops_per_sample, peak_tflops`.
- `__enter__` → `logger.open()`, return self. `__exit__` → `logger.close()`.
- **Deliberately excludes** `resume_segment` / `log_path` (design's full shape) — those are resume concepts, added in PR 4 when used.
- The `gpu_util_sidecar` is **not** folded in — stays a sibling CM in `run_loop` (`with artifacts, gpu_util_sidecar(run_dir, device):`). It needs `device` and gets a path-arg signature change in PR 4; fold-in decision belongs there.

### `initialize_run_dir` → `run_dir.py`
- Moved verbatim from `train.py`. Colocates run-dir lifecycle with `RunArtifacts`; matches design layout and lands PR 4's `prepare_resume` into the right module.
- Import updates: `run_bc_local.py` and `run_bc_modal.py` (both do `from bc.train import bc_run, initialize_run_dir`) split to pull `initialize_run_dir` from `bc.run_dir`.

## Functions extracted into `train.py`

### `print_epoch_summary(epoch, summary, val_summary)`
- Absorbs `run_loop` lines ~425–463: leading blank line, `[epoch N] complete`, mean line, val block / `val skipped`. Computes `mfu_str` from `summary["mfu"]`. Uses existing `_fmt_metric`.
- Boundary: the post-save `print("saved checkpoint…")` + trailing blank stay in `run_loop` (they bracket the save, not the summary).

### `build_dataloader(config, train_samples, device) -> (IterableDataset, DataLoader)`
- Absorbs `bc_run` lines ~291–309: `IterableDataset` build, `dataloader_kwargs`, `DataLoader`, `assert_safe_loader`, dataloader-summary print. Returns both `ds` (for `set_epoch`) and `loader`.
- Boundary: manifest load + split-summary print stay in `bc_run` (orchestration, not dataloader construction).

## Call-site rewrites

- `train_one_epoch`: param `batches_fp: TextIO` → `logger: RunLogger`; the per-batch `_write_jsonl(batches_fp, {...})` → `logger.log_batch({...})`. Rest of signature unchanged (model/optim/scaler stay loose until PR 3).
- `run_loop`: build `RunLogger(run_dir)` + `RunArtifacts(...)`; replace the `ExitStack` (batches_fp/epochs_fp/sidecar) with `with artifacts, gpu_util_sidecar(run_dir, device):`. Epoch row `_write_jsonl(epochs_fp, {...})` → `artifacts.logger.log_epoch({...})`. Console block → `print_epoch_summary(...)`.
- `bc_run`: `ds, loader = build_dataloader(config, train_samples, device)`. `tee_stdio(run_dir / "console.log")` → `tee_stdio(run_dir / "run.log")`; update the adjacent comment.

## The one behavior change: `console.log` → `run.log`
- New runs write `run.log`; existing run dirs keep `console.log`. Aligns with `batches.jsonl`/`epochs.jsonl` naming and the PR-4 suffix rule.
- Stale comment references to "console.log" in `train_config.py:75` and `gpu_sidecar.py:14` get a one-line fix each (they name the renamed artifact directly).
- `tee_stdio` `mode` param: **deferred to PR 4** (exclusive-create only earns its keep on resume; `run_adhoc.py` already relies on the `"w"` default).
