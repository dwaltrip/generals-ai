# Config refactor — implementation handoff

**Date:** 2026-05-31
**Branch:** `quick-model-arch-sweep`
**Status:** Design settled and committed; this kicks off implementation.

## Goal

Make the BC model's architecture self-describing — a `ModelConfig` flowing config-file → model → checkpoint → inference — so two different-width checkpoints can coexist in one eval process. That's the prerequisite for the width sweep ([`5.31-3`](./5.31-3-width-sweep-plan.md)).

[`5.31-2`](./5.31-2-model-config-refactor-design.md) is the spec: code sites, source-of-truth rules, footguns, and verification are all there, and it's been through two Opus review passes with the findings folded in. **Build it, don't re-litigate it.** What follows is only what the spec doesn't already make obvious.

## Sequence by the gates

The build order isn't arbitrary — order it so each no-op-preserving change lands against a fingerprint that catches a regression the moment it happens:

- `model_config.py` + `model.py` first → **`smoke_train.sh`'s loss fingerprint must stay green** (proves `BCModel(ModelConfig())` == today's model).
- then `checkpoint.py` + `state.py` → **`test_parity` must stay green** (proves the legacy-checkpoint load path).

If either moves, stop — the no-op broke.

## Definition of done

Green fingerprints only prove the *no-op*. The capability the refactor exists for needs its own check, and nothing in the no-op path exercises it: **construct → save → load two different-width checkpoints and confirm both load and play head-to-head in one `run_adhoc` process.** That's the acceptance test.

## Where reality might push back

Both are fully specified, but they're where the spec is most likely to meet friction — extra care here, and a good place to check in if it doesn't go as written:

- **Resume `--config` overlay** merges over the *parent's* resolved config, not over defaults (asymmetric with a fresh run). The subtlest new behavior.
- **`train_cli.py`** — retiring the whole flat-flag surface for `--config` is the biggest mechanical change; `test_train_cli.py` is a rewrite, not a tweak.

## Process

Collaborative as usual — check in if something unexpected surfaces (a fingerprint that won't go green, a call site the spec didn't anticipate, an assumption that doesn't hold) rather than pushing through.
