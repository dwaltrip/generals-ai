# Goldens naming reference

*Date: 2026-07-20. The one-page map of the vocabulary set by the goldens naming pass — old names on the left, current names on the right. [7.20-1](7.20-1-goldens-naming-pass.md) records the reasoning behind each choice. The older vocabulary comes from an earlier draft of `confounds-framework.md` as well as session notes that built off of that version (7.08-1 through 7.15-2).*

**Impact labels** (formerly the "effect classes", defined in [the confounds framework](../confounds-framework.md) §2):

| old | new |
|---|---|
| E1 (recipe change) | `recipe-change` |
| E2 break | `contract-break` |
| E2 repair | `contract-repair` |
| E3 ruler | `metrics-change` |
| E3 task | `mechanics-change` |

**Boundary-record fields**: the classification field is `impacts:` (formerly "effect class"). `surface:` keeps its framework name. Field definitions live in the record legend ([7.20-2](7.20-2-boundary-record-legend.md)).

**Surface labels**, the record short forms of the framework §1 rows:

| framework row | record label |
|---|---|
| Obs build, shared path | `obs` |
| Obs build, live path only | `obs-live` |
| Forward semantics (same weight shapes) | `model-forward` |
| Targets / labels | `training-targets` |
| Loss definition | `loss-func` |
| Eval protocol / metric definitions | `eval-protocol` |
| Arch shape / channel count | `arch-shape` |
| The game itself | `game-rules` |

**Channel classes** (formerly the "arithmetic classes", 7.10-2 §4; recorded per channel in the channel summary):

| old | new |
|---|---|
| exact {0,1} indicator | `binary` (values 0 and 1) |
| exact small rational | `category-encoded-exact` |
| correctly-rounded constant division | `int-scaled-by-divisor` |
| log-scaled | `log-scaled` (unchanged) |
